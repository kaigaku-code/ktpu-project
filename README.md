# КТПУ: Контейнеризация и автоматический деплой

Проект выполнен в рамках курса "Python для backend-разработчика". 
FastAPI-приложение упаковано в Docker, настроен CI/CD через GitHub Actions и выполнен деплой на публичный сервер.

## 🌐 Публичный адрес
**Приложение доступно по ссылке:** [ВСТАВЬТЕ СЮДА ССЫЛКУ НА RAILWAY ИЛИ VPS]
*(Swagger UI /docs доступен по пути /docs)*

## 🛠 Технологический стек
- **Backend:** FastAPI, Python 3.11
- **Database:** PostgreSQL (asyncpg, SQLAlchemy)
- **Cache:** Redis (redis.asyncio)
- **Containerization:** Docker, Docker Compose
- **CI/CD:** GitHub Actions
